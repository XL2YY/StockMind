## 🚀 快速开始（免费版）

### 安装

```bash
pip install stockmind
```

### 使用

```bash
# 分析一只股票/ETF
stockmind 159246

# 或者
python -m stockmind.cli 000333
```

免费版输出基础行情 + 涨跌信号 + 综合方向。
