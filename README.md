## 🎯 这是什么？

StockMind 是一个 **A股/ETF 通用分析工具**，不是只针对某一只股票。  
你可以分析 **任何A股和ETF**——贵州茅台、宁德时代、芯片ETF、创业板AI……全部支持。

```bash
# 任意分析，一行命令
stockmind 600519    # 贵州茅台
stockmind 300750    # 宁德时代
stockmind 159246    # 创业板人工智能ETF
stockmind 159995    # 芯片ETF
stockmind 000333    # 美的集团
stockmind 588000    # 科创50ETF
```

### Pro版使用

```bash
# 单股完整分析
stockmind pro 600519
stockmind pro 300750

# 带持仓分析
stockmind pro 159246 --hold 1300@1.136

# 自选股管理
stockmind watchlist add 600519          # 添加贵州茅台到自选
stockmind watchlist add 159246          # 添加ETF
stockmind watchlist list                # 查看所有自选
stockmind watchlist analyze             # 批量分析所有自选

# 多股对比
stockmind compare 159246 159995 588000  # 对比3只ETF

# 热门扫描
stockmind hot                           # 扫描热门ETF/龙头

# 设置止损预警
stockmind pro 159246 --alert 1.02
```
